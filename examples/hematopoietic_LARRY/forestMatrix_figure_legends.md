# Figure legend — forestMatrix_Mega_STRING.pdf / forestMatrix_Baso_STRING.pdf

**Convergence between TIPS/MuTrans-predicted regulators and Weinreb lineage-traced fate genes, Megakaryocyte (A) and Basophil (B) arms** (STRING network; cell-level leiden_r0_8 and, where available, metacell/attractor pipelines).

Each panel shows a forest plot (top) of pairwise Fisher's exact tests between fate-specific gene sets, plotted as odds ratio (x-axis, log10 scale) with 95% Fisher exact confidence intervals (horizontal bars); every point is labeled with the overlap count (k) and exact two-sided P value. Red points compare a computational gene set against the Weinreb lineage-tracing reference; blue points compare two computational methods against each other. Below each forest plot, a gene × evidence-source matrix shows the genes supported by ≥2 evidence sources (filled tile = set membership). All TIPS gene sets use the full set of dualpull network nodes for the relevant fate linkage, not restricted to genes exclusive to that fate, since the Weinreb reference lists are themselves not fate-exclusive. All tests share a common background universe of 3,239 genes (union of the 3,000 cell-level highly variable genes and all genes in Weinreb Table S3).

**(A) Megakaryocyte arm.** Four gene sets are compared: Weinreb fate genes (n=58; in vitro day-2 progenitor DGE genes annotated as Megakaryocyte lineage in Weinreb et al. Table S3); cell-level TIPS (n=6; CF-linkage genes, C17 [Meg] vs C11 [progenitor]); metacell TIPS (n=7; CF-linkage genes, A11 [Meg] vs A4 [progenitor]); and MuTrans drivers (n=41; |correlation| > 0.7 along the A4→A11 SEACells trajectory). Cell-level TIPS shows the strongest, most significant convergence with the lineage-traced fate genes (k=4, OR=117, P=1.4×10⁻⁶), exceeding both metacell TIPS (k=2, OR=56, P=1.8×10⁻³) and MuTrans (k=3, OR=9.1, P=6.6×10⁻³). The matrix shows the 8 genes supported by ≥2 of the 4 sets (GATA1, GATA2, HBB-BS, HBB-BT, MUC13, MYC, PBX1, SLC14A1).

**(B) Basophil arm.** Only 3 of the 4 evidence sources used in (A) exist for this lineage: Weinreb fate genes (n=67); cell-level TIPS (n=3; CM-linkage genes, C11 [progenitor] vs C10 [Baso]); and MuTrans drivers (n=108; |correlation| > 0.7 along the A4→A9 SEACells trajectory). No metacell TIPS set exists here — the metacell/attractor pipeline's dualpull table contains CF-linkage (Meg) edges only, with no CM-linkage (Baso) output — so that comparison and its matrix column are omitted rather than substituted with another gene set. Unlike the Megakaryocyte arm, cell-level TIPS shows weak, non-significant overlap with both the Weinreb fate genes (k=1, P=0.061) and the MuTrans drivers (k=0, P=1); only the MuTrans-vs-Weinreb comparison reaches significance (k=7, P=1.1×10⁻³).
