The TIPS tutorial, "Ordered Yet Selectively Fragile Progenitor Networks" (2019 E8.25 mouse gastrulation dataset), can be viewed [here](https://xyang2uchicago.github.io/TIPS/tutorial/TIPS.html). It covers PPIN construction and topological robustness analysis (Panels A–J, corresponding to Fig. 3d,e of the manuscript); it does not cover TF–target edge reweighting, CM/CF lineage-biased module resolution, CHD-program convergence, or cross-dataset/disease transfer, which are detailed in the manuscript.
